Guardar en GitHub

Los oratorios se guardan en oratorios.json del repositorio. Sin token, la página muestra lo publicado y lo que edites se queda en este navegador. Con un token fine-grained con permiso Contents: Read and write sobre el repositorio, los cambios se suben solos. Es el mismo token que usa la página de Juniors y Postcomunión.
